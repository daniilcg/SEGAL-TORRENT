Торренты без лишнего.

Простой и быстрый клиент для Windows. Открывает .torrent и magnet, показывает прогресс, говорит по-русски и по-английски. Регистрация не нужна.

Скачать для Windows Исходный код

SEGAL-TORRENT.exe · 49.9 MB · Windows 10/11 · файл в репозитории

Один файл

Скачали exe и запустили. Установщик не нужен.

Два языка

Интерфейс на русском и английском, переключается в окне.

Две темы

Тёмная и светлая, в цветах знакомой среды разработки.

Прогресс на виду

Скорость, пиры, сиды, трекеры и список файлов.

Папка запоминается

Следующий торрент предлагается сохранить туда же.

Без аккаунта

Можно сделать программой по умолчанию для .torrent и magnet.

Как начать

  1. 1Скачайте SEGAL-TORRENT.exe.
  2. 2Откройте файл. Windows может один раз спросить подтверждение: подписи у файла нет.
  3. 3Добавьте .torrent или magnet-ссылку и выберите папку.
